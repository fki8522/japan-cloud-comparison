## 五、弹性计费到底怎么算

很多人对"按小时计费"有误解，以为会比包月贵很多。其实狗云的设计是：按小时累加，到月付价格就封顶，超过的部分不再扣费。也就是说，你即使一台机器开机一整月，最多也只扣一个月的钱，不会出现"按小时算下来比月付还贵"的情况。

举个例子：日本-DC2最低配置每小时￥0.0490，一天24小时就是￥1.176，一个月30天就是￥35.28，正好等于月付封顶价。所以你只要机器不销毁，按小时算和直接月付是一样的；但如果你只是临时用几天，按小时计费就比包月划算得多。

还有个被很多人忽略的"暂停留机"功能：如果你只是暂时不用，可以在面板里开启暂停，这期间只扣硬盘和IPv4（如果分配了的话）的费用，CPU、内存、带宽都不扣。对做季节性项目的用户来说，这个功能能省下不少钱。

**Q：日本机房需要备案吗？**
